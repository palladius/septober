# Technology Stack

This document outlines the technology stack for the Septober project.

## Project Status

This project is a work-in-progress to modernize a legacy Ruby on Rails application.

## Current Technology Stack

- **Ruby version:** 1.8 (to be confirmed)
- **Ruby on Rails version:** 3.x
- **Frontend:** jQuery
- **Database:** SQLite3 (development), MySQL (production)
- **Key Gems:** `ric` (currently broken), `acts-as-taggable-on`

## Target Technology Stack

- **Ruby version:** 3.x
- **Ruby on Rails version:** 8.x
- **Frontend:** To be determined (e.g., a modern JavaScript framework like React, Vue, or Svelte).
- **Database:** PostgreSQL is recommended for modern Rails applications, but retaining MySQL is also an option.
